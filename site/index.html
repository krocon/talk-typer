So geht’s

Drei Schritte. Null Umwege.

Kein Server dazwischen. Das Modell rechnet dort, wo du sprichst – auf der GPU deines Macs oder direkt im Browser-Tab.

01 — AUFNAHME

Drück auf Rot.

Ein großer Knopf, Pegel und Wellenform. Nach Sprechpausen wird der Ton in Abschnitte geteilt – Sprachaktivität wird lokal erkannt.

02 — ERKENNUNG

Whisper rechnet. Bei dir.

Nativ in Rust mit candle – auf dem Mac über Metal, sonst auf der CPU oder mit CUDA. Im Browser als WASM im Web Worker.

WhisperON-DEVICE
03 — TEXT

Der Text ist da.

Laufendes Transkript mit Zeitmarken. Kopieren, als Text oder Untertitel exportieren – fertig.
